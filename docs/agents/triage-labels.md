# Triage labels

| Skill role | GitHub label | Meaning |
|---|---|---|
| needs-triage | needs-triage | Maintainer evaluation required |
| needs-info | needs-info | Reporter information required |
| ready-for-agent | ready-for-agent | Specified work that an agent can execute |
| ready-for-human | ready-for-human | Human action required |
| wontfix | wontfix | Work deliberately declined |

Use the role mapping when an authorized triage workflow applies labels. Labels do not constitute deployment, deletion or account authorization.
