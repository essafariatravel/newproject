# Issue tracker: GitHub

Engineering issues and approved specifications belong to GitHub Issues in `essafariatravel/newproject`. Use the installed `gh` CLI or authorized GitHub connector. Resolve repository identity before a write.

Read existing issues with `gh issue view` / `gh issue list`. Publish a new issue or comment only when the owner explicitly authorizes that communication, including through an invoked skill. Local investigation notes remain in the task workspace until publication is authorized. Redact credentials and recovery data before sharing any material.

PRs as a request surface: no.

Use exact current branch/SHA evidence in release work. Production modifications, destructive Preview operations, main merges, billing and legal publication retain their separate approval gates.
