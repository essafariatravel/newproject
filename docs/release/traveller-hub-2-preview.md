# Traveller Hub 2.0 — consolidated Preview
Independent immutable file versions, upload before first application, explicit actual document dates, automatic required-document selection, existing browser Document Guard and final submit path retained. 2 MiB per file, 50 versions per profile, 20 MiB aggregate Preview cap. No automatic trip-specific or stale document reuse; no Staff acceptance inferred. Profile identity correction with evidence blocked; passport renewal allowed and old vault versions no longer eligible. Historical files grouped, no historical mutation. Native drawers and compact directory. Manual upload remains fallback. Server-to-server submission copy, archival, profile merge, structured visa expiry and offline scheduler not in this revision. No new production migration, no paid integration.
Server-side staging of automatically or manually recovered documents now rechecks the source, permissions, programme, type and exact SHA-256 of the browser-reviewed file. The browser only sends a reference and digest; existing staged submission and final evidence storage remain unchanged. No claim of physical blob deduplication across vault and dossiers.
