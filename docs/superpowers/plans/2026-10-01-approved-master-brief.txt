CORE PRODUCT PRINCIPLES
==================================================

ESSAFARIA is a B2B visa operations platform.

Agency experience:
consumer-grade simplicity with professional B2B operations.

Staff experience:
dense operational cockpit.

Core grammar:

Destination
→ Traveller
→ Status
→ Next Action

Preserve:

- one traveller per application
- traveller = full name + nationality only
- Algeria default nationality
- exactly 3 application steps:
  1. Visa & Traveller
  2. Documents
  3. Review & Submit
- DZD operational currency
- immutable wallet ledger
- atomic/idempotent wallet debit
- wallet can never become negative
- tenant isolation server-side
- document size <= 2 MB for visa dossier documents
- submitted dossier locking
- specific replacement/additional document slots may be reopened by Staff
- history/versioning preserved
- inactive catalogue items never break historical dossiers

Do not silently change these rules.
