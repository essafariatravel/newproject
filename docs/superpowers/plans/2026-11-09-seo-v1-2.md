## Global Constraints

- Base SHA `71014b5906cece8cfa5050137bd303f4377f4378` Production; isolated branch.
- No changes to private routes, auth, business logic, DB, migrations, pricing, or visa catalogue.
- All five public pages remain in FR/EN/AR with canonical/hreflang and noindex Preview.
- Public copy avoids false promises, precise visa processing guarantees, and unsupported claims.
- Use existing CSS and design grammar; do not redesign the interface.

## Review Focus

1. URL locale and visitor cookie conflict → URL wins; assert existing SEO contract.
2. Preview incorrectly emits indexable schema → test production-only `Organization` gate.
3. Unsafe structured data field → test `<` escaping and no customer fields.
4. Public content accidentally shows prices or destination catalogue → content contract check.
5. Optimized asset becomes broken or blurry → verify dimensions and rendering on real Preview.
